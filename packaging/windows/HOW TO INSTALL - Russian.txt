WATCHROOM - установка и совместный просмотр (Windows)
====================================================

Watchroom показывает видео с ВАШЕГО компьютера, чтобы вы с друзьями смотрели
его вместе, синхронно, с чатом. Устанавливаете только вы (ведущий). Друзьям
ничего ставить не нужно: они открывают присланную вами ссылку в браузере
(на компьютере или телефоне).

Что нужно
- Windows 10 или Windows 11, 64-бит.
- Около 700 МБ свободного места на диске. (Ещё Watchroom хранит кэш
  подготовленного видео, до 10 ГБ, и сам его очищает.)
- Интернет. От вашей скорости ОТДАЧИ (upload) зависит, насколько хорошей
  будет картинка у друзей (проверить: fast.com -> "Show more info" -> Upload).


1. УСТАНОВКА
------------
1. Дважды щёлкните "Watchroom-Setup-0.2.0.exe".
   (Если вы получили .zip-файл: правой кнопкой -> "Извлечь все..." ->
   "Извлечь", затем дважды щёлкните .exe в новой папке.)

2. Windows может показать синее окно "Windows защитила ваш компьютер".
   Это обычное дело для небольших программ без платной цифровой подписи.
   Нажмите "Подробнее", затем "Выполнить в любом случае".

3. Установка занимает несколько секунд, ничего не спрашивает и не требует
   пароля администратора. Watchroom откроется сам, а на Рабочем столе и в
   меню "Пуск" появится ярлык "Watchroom".


2. СОВМЕСТНЫЙ ПРОСМОТР
----------------------
1. Откройте Watchroom. Нажмите "Open video..." и выберите видеофайл
   (MKV, MP4, AVI, MOV, WebM и другие) или перетащите файл в окно.
   Для видео с YouTube: вставьте ссылку в поле "Paste a YouTube link"
   (под кнопкой) и нажмите "Watch". Видео с YouTube не нагружают ваш
   интернет: каждый смотрит его прямо с YouTube.

2. Подождите, пока внизу появится надпись "Link ready". В первый раз это
   может занять до минуты.

3. Нажмите "Invite" (синяя кнопка справа вверху), затем "Copy".
   Отправьте скопированную ссылку друзьям (Telegram, WhatsApp, ...).

4. Друзья открывают ссылку в Chrome, Edge, Firefox или Safari, вводят имя и
   нажимают "Join". Готово.

5. Любой может запускать, ставить на паузу и перематывать видео - у всех
   оно идёт одинаково. Чат справа. Клавиша F - полный экран.

6. Если Windows спросит "Брандмауэр Защитника Windows заблокировал
   некоторые функции этого приложения" для Watchroom: отметьте "Частные
   сети" и нажмите "Разрешить доступ". Так видео пойдёт к друзьям напрямую
   (быстрее). Если не разрешить, всё равно будет работать, через ссылку.

Пока смотрите, не закрывайте Watchroom и не давайте компьютеру уснуть.
При каждом запуске Watchroom ссылка новая - отправляйте новую.


3. СОВЕТЫ
---------
- Качество: каждый друг выбирает своё (кнопка справа внизу под видео) или
  оставляет "Auto". Если видео подтормаживает у всех, не хватает вашей
  скорости отдачи: попросите друзей выбрать 480p или 360p.
- Вкладка "Room" (справа) показывает, как подключён каждый друг, и
  позволяет закрыть комнату, поставить пароль или удалить кого-то.
- Открывается доступ только к выбранному видео. Другие ваши файлы никто
  не видит.
- В следующий раз на главном экране будет "Continue watching": один щелчок,
  и видео продолжится с того места, где вы остановились.


4. ЕСЛИ ЧТО-ТО НЕ ТАК
---------------------
- "Link unavailable" / ссылка не открывается: проверьте интернет на этом
  компьютере, затем "Invite" -> "Try again". Дождитесь "Link ready".
- После перемотки у друзей крутится значок загрузки: подождите несколько
  секунд, компьютер готовит этот фрагмент.
- Картинка тормозит: пусть друзья выберут качество пониже.
- Чтобы отправить журнал тому, кто помогает: нажмите клавишу Alt (появится
  меню), затем Help -> Open Log Folder, и отправьте файл "watchroom.log".


УДАЛЕНИЕ
--------
Параметры Windows -> Приложения -> Установленные приложения -> Watchroom ->
Удалить.
